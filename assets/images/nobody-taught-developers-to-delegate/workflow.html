# What we do instead

1
Scope
A team lead writes what this ticket introduces, for whom, and how we envisage solving it.
→
2
Catch-up
Problem, outcome and plan checked out loud, so assumed decisions get surfaced.
→
3
/dev-plan
The developer explains how, in what order, and with which patterns, before any agent builds.
→
4
Phase stops
Agents stop after each phase and wait for review. No approval, no progress.
→
5
Visual QA
One agent checks the implementation, then asks the developer to check it too.
> We use the tools, but we don’t delegate the decision-making to them.
