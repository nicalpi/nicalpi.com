# What AI actually changes

ai replaces
  • - [x]Drafting and pattern matching
  • - [x]“Search, paste, tweak until it compiles”
  • - [x]Writing the boring parts
  • - [x]The first version of almost everything
That’s progress. Output got cheap.
ai doesn’t replace
  • - [ ]Responsibility for outcomes
  • - [ ]Context of your system’s history
  • - [ ]Pain of 2am production incidents
  • - [ ]Deciding what actually matters
That’s where the value moved.
