## 2. "Jev"

**Answer: verified.** Jev is real, and the release date is 15 Sep 2026 — a week before 22 Sep, not "a few days" as Nic recalled, but it is very likely the model he means (nothing else named "Jev" or similar surfaced).

- Jev is a proprietary AI model from **TypeSafe AI**, a San Francisco company founded in 2024 by ex-OpenAI engineer Diogo Almeida.
- Released in limited early access on **15 September 2026**, alongside a $40M seed round led by DCVC.
- It is not an LLM: it's described as a "System One Model" that returns typed values with calibrated probabilities/confidence scores instead of natural-language text, intended to be consumed by other software. TypeSafe claims it runs 40–200x faster than frontier LLMs on comparable tasks and "cannot hallucinate."
- Named after 19th-century economist William Stanley Jevons (Jevons paradox).
- Source: [TechCrunch, "A new kind of AI model from a ChatGPT inventor is thrilling developers," 18 Sep 2026](https://techcrunch.com/2026/09/18/a-new-kind-of-ai-model-from-a-chatgpt-inventor-is-thrilling-developers/)
- Corroborating: [Wikipedia, "Jev (AI model)"](https://en.wikipedia.org/wiki/Jev_(AI_model)), [The Register, "TypeSafe AI debuts model for machines that plays Doom," 16 Sep 2026](https://www.theregister.com/ai-and-ml/2026/09/16/typesafe-ai-debuts-model-for-machines-that-plays-doom/5296711), [heise online, "AI model 'Jev' to make machines decide faster"](https://www.heise.de/en/news/AI-model-Jev-to-make-machines-decide-faster-11457071.html), [DataCamp, "Jev: TypeSafe's System One Model That Never Hallucinates"](https://www.datacamp.com/blog/system-one-models-jev), [LangChain blog, "What Is Jev?
