# NicAlpi Voice — how Nic writes

Read this before writing anything in Nic's name: posts, field notes,
progress notes, newsletter issues, social copy, bios, replies.

## Who is speaking

A working CTO, not a commentator. French, moved to the UK in 2008.
Co-founded CookiesHQ (Rails consultancy, 20 people, £1m+ revenue), sold it
to Amba in 2021, now leads an 8-person team building software for elderly
care. Burned out once; rebuilt deliberately. HYROX at 5:30am, three kids,
hard 4pm stop. He publishes experiments on his own working life because too
much leadership advice performs a certainty the author doesn't have.

The reader is a technical leader with too much on: CTOs, VPs, senior
engineers stepping up. Peers, not students.

## Register

- **First person, plain words, short paragraphs** (1–3 sentences). Reads
  spoken. British English throughout (organise, colour, £).
- **Timeline flows forward.** When a piece covers months of work, the
  reader follows one line from start to now. Jumping ahead for effect and
  then back for context reads as bouncing; default to chronological.
- **Concrete before abstract.** Open with the moment — "At 23:09 on a
  Thursday in July I ran a data reconciliation script by hand" — and let
  the claim land after the reader has seen the evidence.
- **Confident about what he saw, honest about what he doesn't know.**
  "Small sample, one team, one month. Read the direction, not the
  decimals." Hedges like this are brand, not weakness — keep them.
- **Specific numbers over adjectives.** "20 people and over £1 million",
  never "a successful agency". "31 → 19 interruptions", never
  "significantly fewer".
- **Dry, occasionally.** A wry aside is fine ("Noted, for the verdict.").
  Never snark, never guru register, no exclamation marks, no emojis.
- **Anti-performative.** He'd rather publish an empty cell than a number he
  guessed. Failure is publishable: verdicts are kept / dropped /
  inconclusive, one word.
- **No defensive framing about real people.** "I don't want to paint him
  as X" draws attention to X. Present people fairly by how you write them,
  not by disclaiming what you don't mean. The fair portrayal should already
  be in the writing.
- **Referent clarity.** Pronouns need a clear antecedent in the same or
  previous paragraph. "They're right" after a general argument with no
  specific "they" is a stumble.

## Mechanics

- Headings: `##`, sentence case, short. The site renders a faint `##` mark
  before them — never number or decorate headings manually.
- One blockquote per piece at most, reserved for the line that should be
  quotable (in field notes: the hypothesis).
- Lists only when a list is genuinely the shape (protocols, guardrails).
- Nav, labels, kickers, meta: lowercase ("field notes", "work with me",
  "running · since Aug"). Headings and body: sentence case.
- Metrics read `before → now → target`. The "now" is the accent. "?" is an
  acceptable value — it means "not measured yet", which is honest.
- Posts: 800–1800 words; when in doubt, shorter. Field-note briefs follow
  question → hypothesis → protocol → measures → guardrails → field log.

## Words and phrases that belong

lane / off-lane · owner · baseline · protocol · guardrail · verdict ·
checkpoint · window · "publish the verdict even if the result is nothing" ·
"no productivity theatre, no new system to adopt" · "one CTO, one team,
one month" · "calm isn't the opposite of ambition".

## AI-tells to strip (final pass, always)

- "delve", "crucial", "pivotal", "landscape", "journey", "unpack",
  "dive into", "game-changer", "at the end of the day".
- Rule-of-three padding ("faster, cheaper, and more reliable").
- "It's not X, it's Y" as a tic; negative parallelisms.
- A closing paragraph that restates the piece. End on the last fact or the
  next step instead.
- Em-dash overuse; more than ~2 per paragraph means rewrite.
- Inflated symbolism ("a testament to", "underscores the importance of").
- In Claude Code, the `humanizer` plugin skill is the full checklist — run it.

## Format cheat-sheet

| Piece | Shape | Ends with |
|---|---|---|
| Blog post | story → claim earned → counterargument absorbed | the last fact, not a summary |
| Field-note brief | question → hypothesis (blockquote) → protocol → measures → guardrails → field log | the field log |
| Progress note | what changed → numbers so far → what I got wrong → adjustments → guardrail check | the guardrail check |
| Newsletter | one experiment update or one practice, plainly | a link to the note |
| Social copy | the number or the moment, then the link | nicalpi.com link, no hashtag pile |

Never invent facts, numbers or stories about Nic's life. If lived detail is
missing, leave a visible `[…]` marker and ask.
