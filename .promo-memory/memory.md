# Promo memory — how Nic promotes

Read by `promo-drafter` and `/promo-draft` before any copy. Two sections:
**Social voice** is the stable guide (seeded from the writing voice, adapted
for platforms). **What works** is evidence from past promotion rounds — which
formats, angles and hooks got traction. `/promo-draft` appends there after
each completed calendar.

## Social voice

Same person as the blog: first person, plain words, British English. But
shorter, sharper, more direct. Adapted per platform:

- **LinkedIn**: story-shaped, slightly longer (1,500-2,500 chars), opens with
  a moment or a number. Written for the feed — a reader who never clicks
  through still got value. No hashtags by default. No emojis by default.
  Links in the first comment, never the body.
- **Twitter/X**: hook-first, one idea, under 280 characters. Threads build
  one claim per tweet. Written to provoke replies — author-engaged replies
  get algorithmic lift. No hashtags, no emojis.

Both: no guru register, no social-media-manager polish, no clickbait. The
social post is an extension of the blog voice, not a marketing channel.
Confident about what he saw, honest about what he doesn't know.

Strip the same AI-tells as the blog: delve, crucial, pivotal, landscape,
journey, unpack, game-changer, leverage, seamless, cutting-edge, unlock,
paradigm shift, robust, empower; rule-of-three padding; "it's not X, it's Y";
inflated symbolism; more than one em-dash per post.
